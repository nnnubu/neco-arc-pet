# 猫姬桌宠（Neco Arc Pet）

一个像素风 Neco Arc 桌面宠物：能聊天、能翻唱、能语音合成、有 100+ 种动作，支持中英文界面。

## 快速开始

1. 双击 `启动桌宠.vbs`（无控制台窗口），或 `npm start`
2. 桌宠出现在屏幕，右键/打开「猫姬控制台」进入各功能面板

> 首次使用语音合成 / 翻唱功能，需先安装语音扩展包（见下文「语音扩展包」）。

## 教程

### 一、配置 AI 对话

1. 打开总面板 → 侧边栏「AI 设置」
2. 在「文本生成模型」下填写三项（在你使用的模型服务商处获取）：
   - 文本生成模型：模型名称
   - 文本 API 密钥：你的密钥
   - 文本接口地址（Base URL）：接口地址
3. 点「测试文本模型」确认可用，再点「保存」
4. 回到「对话」面板即可和猫姬聊天

### 二、配置语音（可选）

未安装语音扩展包时无需配置；安装后：

1. AI 设置 → 「语音合成模型」填写模型 / 独立密钥 / 独立接口（与文本模型相互独立，可用不同服务商）
2. 想免费出声：勾选「指定模型失败时自动用免费兜底」，未填模型时也会自动使用微软语音（Edge TTS / 系统语音）
3. 「测试语音模型」可验证；不配置也不影响聊天（回复以文本气泡显示）

### 三、配置知识库（可选）

1. 把 `.md` 资料放入 `assets/arc-knowledge/`（每块用 `## 标题` 分块）
2. **完全退出桌宠后重新启动**（资料库启动时加载）
3. AI 设置 → 「嵌入模型」填写模型 / 密钥 / 接口启用向量检索；不填则自动用本地关键词检索（免费离线）
4. 触发方式：智能判断 / 总是检索 / 自定义关键词，按需选择

### 四、翻唱

1. 侧边栏「翻唱」→ 把音频文件拖入（或点击选择）
2. 点「开始翻唱」：自动分离人声 → 变声喵声 → 混音
3. 完成后自动播放，勾选「显示桌面歌词」可看歌词（本地 `.lrc` 优先，否则联网搜索）

### 五、语音合成

侧边栏「语音合成」：输入文本 → 选声线 / 情绪强度 / 音高 → 生成猫姬音色语音；可「应用到聊天 / 翻唱」。

### 六、随机发声 / 动作

- 随机发声：AI 设置中开启，桌宠会偶尔用本地语音素材叫一声（基础包自带素材，无需语音扩展包）
- 动作：侧边栏「动作」可播放 100+ 种动作，支持随机动作

### 语音扩展包

- 语音合成与翻唱依赖 Python 语音引擎（约 1.4GB，不入代码仓库）
- 扩展包内含：Python 依赖环境、RVC 音色模型与特征索引、hubert/rmvpe 权重、ffmpeg、口癖音频
- 将语音扩展包解压到程序根目录（与 `启动桌宠.vbs` 同级），重启桌宠自动生效
- 也可在开发版侧边栏用「生成语音扩展包」按钮自行打包

## 从源码自建（开发者）

普通用户无需自建，直接使用发布的基础包 + 语音扩展包即可。从源码重建开发环境：

1. **Node 侧**：安装 Node.js 后执行 `npm install`，再 `npm start` 启动。
2. **Python 侧**：安装 Python 3.10（Windows x64），新建虚拟环境后安装锁定依赖：
   ```
   pip install -r requirements.txt
   ```
   torch / torchaudio 需使用 PyTorch 官方 CUDA 12.4 轮子（`requirements.txt` 头部有对应说明与命令）；默认安装会拉到 CPU 版。
3. **模型权重与二进制文件不在源码仓库**，需按下表补齐到对应路径：

   | 路径 | 文件 | 来源 |
   | --- | --- | --- |
   | `voice/assets/` | `hubert_base.pt` | Hubert 内容编码器，tts-with-rvc 框架首次运行联网从 HuggingFace 拉取 |
   | `voice/assets/` | `rmvpe.pt` | 音高提取模型，同上 |
   | `voice/models/agg/` | `model.pth`、`model.index` | agg 猫姬音色模型与特征索引，随语音扩展包提供 |
   | `voice/models/lumina/` | `Neco-ArcLumina.pth`、`*.index` | lumina 音色模型与特征索引，随语音扩展包提供 |
   | `voice/bin/` | `ffmpeg.exe` | 音频转码工具，取 ffmpeg 官方 Windows 构建 |

## 常见问题

- **对话没声音**：未安装语音扩展包，或未配置语音模型且未开启免费兜底——属于正常降级，文本照常显示
- **知识库资料不生效**：新增 `.md` 后需完全退出并重启桌宠

## 配置与隐私

- 所有 AI 密钥、接口等配置保存在本地 `assets/ai-config.json`，**不会上传或入库**
- 代码仓库不包含：密钥配置、模型文件、依赖目录、日志与缓存（见 `.gitignore`）
